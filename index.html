Tambah Soal Manual
Isi formulir soal secara manual.
📄
Import dari Excel (.xlsx)
Isi tabel: 1 baris = 1 soal. Tipe PG (TWK/TIU), TKP (kolom Kunci = skor 1–5 tiap opsi), atau Kecukupan (pilihan baku otomatis).
📄
Import dari Word (.docx)
Format tabel sama seperti template Excel; tabel di dalam sel Pertanyaan (soal TIU bertabel) tetap terbaca — gambar yang ditempel langsung di kolom "Gambar"/Pertanyaan/Opsi otomatis terdeteksi & terunggah, tanpa perlu pilih file terpisah.

Kategori SKD: beri nama kategori TWK, TIU, dan TKP (nama boleh memuat kata itu). Soal TWK/TIU: benar = 5 poin. Soal TKP: tipe TKP dengan skor 1–5 pada tiap opsi. Soal TIU Kecukupan Data cukup isi tipe Kecukupan (lima pilihan baku terisi otomatis). Kolom Topik dipakai untuk analisis materi yang kurang per peserta.

Kategori: semua soal yang diimpor dari halaman ini otomatis masuk ke mapel yang sedang dibuka — isi kolom "Kategori" di file tidak perlu diisi (diabaikan).

Soal bergambar (Excel): di kolom "Gambar" pada tabel, cukup ketik nama file gambarnya saja (mis. soal1.jpg) — lalu sebelum klik kartu Import, klik dulu "🖼 Gambar Pendukung" di kartu yang sama & pilih semua file gambar terkait sekaligus (boleh banyak file). Sistem otomatis mencocokkan berdasarkan nama file. Boleh juga langsung isi kolom "Gambar" dengan link gambar publik.

Soal bergambar (Word): tempel/sisipkan gambarnya LANGSUNG di dalam sel tabel Word (kolom "Gambar", atau bahkan di tengah teks Pertanyaan/Opsi) — saat diimpor, gambar tersebut otomatis terdeteksi & terunggah sendiri, tidak perlu lagi mengetik nama file atau memilih file gambar terpisah. Tombol "🖼 Gambar Pendukung" di kartu Word tetap bisa dipakai sebagai cara alternatif (cocok nama file) kalau kamu lebih suka begitu.

Soal yang dibuat tapi belum dipakai bisa diarsipkan supaya tidak mengganggu daftar aktif, lalu diedit & dikembalikan kapan saja lewat filter status "Arsip". Centang "Riwayat" untuk melihat soal yang sudah pernah dipakai di ujian mana saja.

Data Siswa

Kredensial akun siswa. Tambahkan satu per satu, atau impor massal dari file .xlsx/.csv.

Tambah Siswa Manual

Impor Massal

Kolom dibaca dari judul kolom (urutan bebas), sesuai Kartu Login: Nama Peserta, NISN, Tempat Lahir, Tanggal Lahir (atau satu kolom Tempat, Tanggal Lahir), Username, Password, plus Kelas dan Jenis Kelamin (L/P) bila ada. Username/password yang sudah ada di file dipakai apa adanya (tidak diubah); bila kosong dibuatkan otomatis. Siswa dengan username yang sama diperbarui datanya, bukan digandakan. File lama berformat nama, kelas, username, password tetap bisa diimpor.

Isi kolom ini kalau semua siswa di file yang mau diimpor berasal dari satu kelas yang sama (mis. hanya kelas 9A) — nilainya akan dipakai untuk semua baris, menggantikan kolom "kelas" di file.

Dua tombol ini adalah lapisan cadangan manual untuk berjaga-jaga, atau untuk memindahkan data yang sempat dibuat saat masih Mode Lokal ke Google Sheets begitu Mode Server diaktifkan.

Menarik ulang seluruh Bank Soal, Ujian, dan Data Siswa dari Google Sheets saat ini juga (tanpa menunggu 8 detik), sekaligus menyimpan salinannya sebagai cadangan lokal di perangkat ini.

Mengirim seluruh data yang ada di penyimpanan lokal (Mode Lokal) perangkat ini — Bank Soal, Data Siswa, Ujian — ke Google Sheets yang sedang terhubung. Pakai sekali saat pertama kali pindah dari Mode Lokal ke Mode Server; mengulanginya akan membuat data ganda.

Ubah Data Siswa

Buat Ujian

Soal diambil dari kategori TWK, TIU, dan TKP di Bank Soal (nama kategori memuat TWK/TIU/TKP). Isi jumlah soal tiap subtes (resmi: TWK 30, TIU 35, TKP 45 = 110 soal) lalu klik Susun Soal; soal diambil dari paket yang dipilih di atas. Urutan di layar peserta selalu TWK → TIU → TKP.

Penilaian: TWK & TIU benar = 5, salah/kosong = 0; TKP tiap opsi 1–5. Lulus bila semua ambang batas terpenuhi. Nilai 0 = tidak disyaratkan.

Kelas yang token-nya belum diaktifkan tidak bisa memulai ujian walau tahu tokennya. Pengaturan per kelas bisa diubah kapan saja dari daftar ujian (tombol 🔑 Token Kelas).

Setelah siswa menekan Selesai, nilai dikirim ke server lebih dulu, lalu siswa mengunggah foto coretan (JPG/PNG/HEIC, boleh lebih dari 1). Nilai Lulus/Remedial baru tampil setelah foto terkirim. Foto muncul di sebelah nilai pada Rekap Nilai.

Setiap nilai (0, 1, 2, … 100) bisa punya pesan sendiri. Tidak perlu mengisi satu per satu: unduh template Word, ubah pesannya, lalu import — semua nilai terisi sekaligus. Pesan yang dikosongkan otomatis memakai default.

Isi cepat: satu pesan untuk beberapa nilai
